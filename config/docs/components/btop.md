# Btop

Btop is a terminal-based resource monitor displaying CPU, memory, disk, network, and process graphs.

---

## Configuration File

* `btop/btop.conf` — Theme and background settings.

---

## Configuration Details

* **Theme**: `color_theme = "catppuccin-mocha"`.
* **Background Transparency**: `theme_background = false`.

Disabling the theme background allows Btop to inherit Kitty's 40% background opacity and Hyprland's compositor blur, maintaining visual consistency with the rest of the terminal environment.
